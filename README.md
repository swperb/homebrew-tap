# swperb Homebrew tap

```sh
brew install swperb/tap/imgcli
```

[imgcli](https://github.com/swperb/imgcli) — a dependency-free, ffmpeg-style
command-line tool to convert, resize, crop, filter, and composite still images.

```sh
brew install --cask swperb/tap/anvilcad
```

[AnvilCAD](https://github.com/swperb/anvilcad) — free and open-source parametric 3D CAD
with its own geometry kernels. The cask is generated by
`packaging/update-package-managers.sh` in that repository.
